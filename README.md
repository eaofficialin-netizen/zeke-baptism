# Zeke Abram Eric — Baptism invitation

## Upload to GitHub
1. Extract this ZIP on your computer. Do not upload the ZIP itself.
2. Open your public repository named zeke-baptism.
3. Click “uploading an existing file” (empty repository) or Add file → Upload files.
4. Drag ALL extracted contents into the upload area: index.html, app.js, app.css, styles.css, assets folder, README.md and .nojekyll if visible. Keep the assets folder intact. index.html must appear at the repository root, not inside another folder.
5. Click Commit changes.
6. Open Settings → Pages. Under Source choose Deploy from a branch.
7. Select main and / (root), then Save.
8. Wait for GitHub to finish publishing. Open the address shown in Pages:
   https://eaofficialin-netizen.github.io/zeke-baptism/

No build command, installation, login for guests, or paid service is needed for this package.
Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Included
- Existing invitation design, opening interaction, family sections and water-ripple animation.
- Six original photo files, copied without editing or re-encoding.
- Desktop and mobile journey videos, with both poster images.
- Locally bundled CSS, JavaScript and fonts. No remote asset dependency.
- Live countdown with days, hours, minutes and seconds, fixed to 17 October 2026 at 08:30 IST (03:00 UTC). It stops at zero once the ceremony starts.
- Church and reception directions; sharing with a copy-link fallback.
- Reduced-motion support from the original project.

The existing journey video animates photographs; it is not footage filmed inside the church. No music was supplied in the project.
Preview the full animation through GitHub Pages or a local web server; double-clicking index.html may restrict the video's loading in some browsers.
